# Design system (studio chrome and phone)

Two surfaces, two palettes. **The studio** (gallery, top bar, sidebar, editor, device dock) is a dark, neutral developer
tool. **The phone** renders a wallet, so it has its own light and dark palettes and an iOS-flavoured grouped layout.

## Foundations
- **Tokens:** `src/styles/tokens.css` (surfaces, hairlines, text steps, radii, shadows, motion), one cool accent for the
  chrome (`--studio-accent`) and the wallet blue (`--accent`) kept for the phone. `[hidden]` always wins over a display rule.
- **Type:** Inter (variable, self-hosted via `@fontsource-variable/inter`, no external request) for the studio; the phone
  uses the platform font (SF on iOS, Google Sans/Roboto on Android) with Inter as the fallback. JetBrains Mono for code
  and addresses. Tight tracking on titles, tabular numbers on every amount.
- **Icons:** Lucide (ISC), 24px stroke icons, 1.75 stroke, through `src/ui/icons.ts` (`icon()` and `iconButton()`).
  Only the icons listed there reach the bundle. Icons are decorative; the button carries the accessible name.
- **Radii:** 6 / 8 / 12 / 16 / 22 / pill. **Spacing:** 4-pt steps, 16 px gutters. **Motion:** 140 ms ease-out, none under
  `prefers-reduced-motion`.

## Components
- Buttons: `.btn`, `.icon-btn` (36 px, hairline border, hover lift), ghost variant. Segmented control: `.segmented`.
- Device dock: one panel under the phone: platform (iOS / Android), appearance (light / dark), Share menu, Deploy.
- Menu (`src/ui/menu.ts`): arrow keys, Enter, Esc, outside click; focus returns to the trigger. Toast (`toast.ts`)
  replaces `alert()` for confirmations.
- Studio theme: dark by default, light when the system asks (`prefers-color-scheme`), or pinned with the toggle
  (`src/ui/studio-theme.ts`, `data-theme` on `<html>`). All studio colors are tokens in `tokens.css`.
- Motion: screens slide in 280 ms (ease-out), dialogs rise 240 ms, logos fade 220 ms, skeletons shimmer; all off under
  `prefers-reduced-motion`. Android adds a Material press ripple.
- Editor: transparent textarea over a colored `<pre>` (`json-highlight.ts`); errors are located by an own JSON scanner.
- Phone: cards on a quiet canvas (`--ph-bg`, `--ph-card`, `--ph-line`), large title, grouped token list, Send (filled with
  the token accent) and Receive (outlined) with arrow icons, 54 px high.

## Phone mode
A link opens as the bare phone interface on a phone (see CONTRIBUTING, "Phone mode"). Safe areas come from
`--safe-top` / `--safe-bottom`: 32 px / 0 on the framed device, `env(safe-area-inset-*)` on a real phone.
